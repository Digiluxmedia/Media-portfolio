DigiLuxe Media Interactive Portfolio — Version 7

PREVIEW
1. Keep this HTML file in the same folder as the "prototypes" and "assets" folders.
2. Open digiluxe_media_portfolio_animated_v8.html in Chrome.
3. The Digital Experiences cards use cropped screenshots of the actual supplied website prototypes.
4. Click any Digital Experiences card to open its matching HTML prototype.

NOTES
- Website preview images are cropped to remove the browser toolbar and desktop dock.
- The prototype pages are concepts/demos, not necessarily live client deployments.
- Google Fonts and any remote image sources require an internet connection.
- Contact form functionality depends on the configuration in the HTML; no server backend is included in this local bundle.


Version 8 update: The footer Project enquiry label and Start your enquiry button open the DigiLuxe Media Microsoft Form in a new tab.
